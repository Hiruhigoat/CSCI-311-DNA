# DNA Sequencer

Given a DNA sequence compare it to other known sequences to find the one most similar

## Description

DNA are long strings of genetic information. Given a new dna sequence if it is compared to other dna sequences, similarity could help scientist test out hypothesis more effeciently. Due to DNA sequences being large being able to effeciently find the best match is imperative for biology people.

## Getting Started

### Dependencies

* **Java Development Kit (JDK):** Version 17 or higher.
* **JavaFX:** Handled automatically—the launcher scripts will download and configure local JavaFX binaries into `lib/` if not detected on your system.

### Installing

Clone from the repo from https://github.com/Hiruhigoat/CSCI-311-DNA.git

```bash
git clone [https://github.com/Hiruhigoat/CSCI-311-DNA.git](https://github.com/Hiruhigoat/CSCI-311-DNA.git)
cd CSCI-311-DNA
```

### Executing program

Linux:
```bash
./run.sh
```

Windows:
./run.bat

Mac:
Buy another computer and see above
